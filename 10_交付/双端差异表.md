# 双端差异表（H5 / 微信小程序）（D-33 / C02）

> 用途：面试三问之一「uni-app 一套代码两端，差异到底在哪」的**代码级答案**，也是切域名/切云开发时的改造索引。
> 口径：每行都指到真实文件与行号；未实现/未验证的写「未实现/未验证」，不写好听话。

## 一、总览

| 维度 | H5 | 微信小程序（mp-weixin） | 差异根因 |
|---|---|---|---|
| 构建命令 | `npm run build:h5` → `dist/build/h5` | `npm run build:mp-weixin` → `dist/build/mp-weixin`（`app.json` 6 页 / tabBar 2） | 同一套 `src`，编译目标不同 |
| 运行验证程度 | ✅ 全链路实跑（登录/列表/详情/表单/我的/退出/401） | ⚠️ **仅编译级**：产物生成、页数校验通过；真机未跑（缺 AppSecret/体验版，C07） | 外部依赖 |
| 接口通道 | 直连后端 8092（`src/utils/request.ts:120`） | 走云函数代理 8093（`request.ts:124`） | 未备案域名不能配 `request` 合法域名 |
| 登录方式 | 账号口令 `POST /api/auth/login`（`pages/login/index.vue`） | `uni.login` 取 code → 8094 换 openid → `loginByOpenid`（`login/index.vue:134`） | 小程序无表单账号体系，走微信身份 |
| 鉴权头 | `Authorization: Bearer <JWT>` | 云函数侧加 `X-Sign/X-Timestamp/X-Nonce`（HMAC）+ 透传 token | 后端对 `X-Client: cloud` 或带签名头的请求强制验签 |
| 样式单位 | px / vw / `@media (min-width:900px)` 桌面版式 | rpx（750 设计基准）+ 原生导航栏 | 小程序无 CSS 媒体查询语义、无浏览器视口 |
| 页面标题语义 | `h1`（`/* #ifdef H5 */` 分支，首页/详情各 1 个） | 无 `h1`（`text/view` 渲染） | 小程序无 HTML 语义标签 |
| 分享 | 无（浏览器原生分享/复制链接） | **未实现**（`onShareAppMessage` 全仓 0 命中） | 设计书模块 5 只要求「能力对照」，未要求实现 → 记 v1.1 |
| 支付 | 无 | 无 | 排除范围（需企业主体 + 支付资质） |
| 本地存储 | `uni.setStorageSync` → localStorage | 同 API → 小程序 Storage | 键名统一：`ub_token`/`ub_user`/`ub_privacy_agreed`/`ub_booking_draft` |
| 隐私授权 | 仅隐私页入口，无系统弹窗 | `__usePrivacyCheck__` + `wx.getPrivacySetting`/`requirePrivacyAuthorize`（`App.vue:26-40`） | 小程序平台强制 |
| 服务地址 | 可改 `env.ts` 一处 | 同（但产物里是 `127.0.0.1`，真机不可用，Q-013） | 需换云开发环境 id / 备案域名 |
| 底部导航 | 自绘 tabBar（桌面 ≥900 收窄 480 停靠条） | 原生 tabBar | 平台控件差异 |
| 返回 | 页面内「← 返回」（`navigateBack`，栈空兜底 `reLaunch` 首页） | 原生左上返回 | 小程序默认有导航栏 |

## 二、逐项细节（可对代码）

### 1. 登录

| 项 | H5 | 小程序 |
|---|---|---|
| 触发 | 登录页输入 `demo/welcome1` | 「微信一键登录」按钮 → `uni.login({provider:'weixin'})` |
| 凭据 | `{account, password}` | `code` → `getOpenid` 云函数（8094）→ `openid` |
| 后端接口 | `/api/auth/login`（account 分支） | `/api/auth/login`（openid 分支，账号不存在自动建号） |
| 实测 | ✅ `e2e_result.json`：token 185B、跳「我的」、字段级 40101 红字 | ⚠️ mock 微信 `goodcode`→200、`badcode`→400（`smoke_cf.txt`）；真实 `code2session` 需 `MP_APPSECRET` |
| 风险 | CORS：401 也必须有 `Access-Control-*`（Q-037 已修 `CorsHeaderFilter`） | 无 AppSecret 时所有 openid 登录 50001 |

### 2. 请求与签名

| 项 | H5 | 小程序 |
|---|---|---|
| 报文 | `GET/POST http://127.0.0.1:8092/api/...` | `POST http://127.0.0.1:8093/` body=`{action,payload,token}` |
| 签名 | 不签名（本地 dev 直连） | `shared/signer.js` HMAC-SHA256，错签→40102 |
| 超时/重试 | 3s，5xx/网络失败重试 1 次，业务错不重试（`request.ts:127-176`） | 云函数 3s 超时 + 重试 1 次（`smoke_cf.txt` 实测墙钟 6047ms→504/50002） |
| 错误码 | 40101/40103 清会话并由页面提示；50002 统一 toast | 同码透传（代理不改码） |
| 实测 | ✅ 4 调用 0 漂移（`06.5_契约/契约校验记录.md`） | ✅ 18 项 PASS（含 1MB 413、挂起后端 504） |

### 3. 样式与布局

| 项 | H5 | 小程序 |
|---|---|---|
| 单位 | px/vw；rpx 不参与 | rpx（750 基准） |
| 响应式 | 375/414/1440 三档；≥900 桌面双版式（首页两栏、详情左文右图、表单 680） | 单套 rpx，无桌面概念 |
| 条件编译落点 | `/* #ifdef H5 */` 样式块：`index/my/detail/form/login/privacy` 6 页 + `App.vue:55` | 无 `#ifdef MP-WEIXIN` 样式块（默认即小程序） |
| 实测 | ✅ 375/414 横向溢出 0（`rework_layout.json`）、1440 5/5 PASS（`step6_desktop_probe.json`） | ⚠️ 仅 `check:build` 6 页通过；未真机量版 |
| 已知偏差 | — | 4:5 出血图位用 `height:125vw` 替代 `aspect-ratio`（WXSS 不支持） |

### 4. 能力差异（分享/支付/剪贴板/扫码）

| 能力 | H5 | 小程序 | 本项目处理 |
|---|---|---|---|
| 分享到微信 | 无原生分享 | `onShareAppMessage` 可接 | **未实现**（记 v1.1，非缺陷） |
| 支付 | 无 | `wx.requestPayment` | **不做**（排除范围） |
| 扫码 | 摄像头/二维码库 | `uni.scanCode` | **不做** |
| 复制链接 | `navigator.clipboard` | 无剪贴板到浏览器 | 不涉及 |

### 5. 存储与隐私

| 键 | 写入位置 | 用途 | 清除时机 |
|---|---|---|---|
| `ub_token` | `utils/auth.ts:33` | JWT | 40101/40103、退出登录 |
| `ub_user` | `auth.ts:34` | 展示昵称/账号 | 同上 |
| `ub_privacy_agreed` | `App.vue:34`、`privacy/index.vue:56` | 隐私同意标记（仅小程序弹窗用） | 用户清缓存 |
| `ub_booking_draft` | `utils/bookingDraft.ts:21` | 未登录跳登录前的表单草稿（Q-043） | 回填后即删、提交成功即删、套餐不匹配丢弃 |

隐私授权路径：**仅小程序**有系统级弹窗；H5 只提供协议页与「同意」按钮，不做强制拦截（浏览器无对应能力）。

### 6. 上线前的必改项（按阻塞程度）

| # | 必改项 | 阻塞 | 改法 |
|---|---|---|---|
| 1 | `env.ts` 里 `127.0.0.1:8093/8094` | 真机全挂 | 换成云开发环境调用（`wx.cloud.callFunction`）或已备案 HTTPS 域名 |
| 2 | 无 `wx.cloud.callFunction` 分支 | 同上 | 在 `request.ts` 增加 cloud 通道分支（Q-013 遗留） |
| 3 | 隐私协议仍是 demo 占位 | 提审必驳 | 替换正式文本并逐项对齐 `隐私一致性核对表.md` |
| 4 | 分享未实现 | 不阻塞 | v1.1 补 `onShareAppMessage` |

## 三、结论（面试口径，可直接背）

> 一套 `src` 出两端，真正分叉的只有 4 处：**登录身份（账号 vs openid）、请求通道（直连 vs 云函数代理+HMAC）、样式单位与桌面版式（rpx vs px+媒体查询）、HTML 语义（h1）**。其余（页面结构、状态管理、存储键、错误码）完全共用。代价是：小程序端多一跳云函数（冷启动 + 配额），且真机验证必须等 AppSecret 与域名就绪——这两项是本项目 C07–C09 未闭环的唯一原因。
